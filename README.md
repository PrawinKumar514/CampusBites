## 📖 Project Overview

**Campus Bites** is a modern AI-powered campus food ordering platform designed for educational institutions. The application enables students to browse canteen menus, place food orders, make secure payments, track orders in real-time, and manage profiles through an intuitive and responsive interface.

The platform integrates **Next.js**, **Firebase**, **Tailwind CSS**, **Radix UI**, and **Google AI (Genkit)** to provide a seamless digital food ordering experience. An advanced **Admin Dashboard** allows administrators to monitor orders, users, and revenue analytics efficiently.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/PrawinKumar514/campus-bites.git
cd campus-bites
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Application will start at:

```text
http://localhost:3000
```
