# **App Name**: CampusCravings

## Core Features:

- Menu Browsing: Browse daily cafeteria menus with categorized food items and descriptions.
- Order Customization: Customize food orders with options and special instructions. Allow users to leave instructions in a text field. Use AI to determine the best way to prepare an order, or suggest ingredients to use or not to use. Use an LLM 'tool' that accesses cafeteria data about student food allergies.
- Order Placement: Place orders with in-app submission to cafeteria.
- Secure Payment: Process payments securely within the app using mocked credit card transactions.
- Order Tracking: Track real-time order status with estimated pickup time and notifications.
- Pickup Scheduling: Schedule a specific pickup time during cafeteria hours.
- Sign In: Sign in using college mail id and password.
- Sign Up: Sign up using college mail id and password.

## Style Guidelines:

- Primary color: Indigo (#4CAF50) to evoke feelings of credibility and dependability, referencing Google Flow/Firebase Studio's design ethos.
- Background color: Light gray (#F0F4F3), near white, to provide a clean and modern aesthetic, in keeping with contemporary tech interfaces.
- Accent color: Teal (#009688) to draw attention to key interactive elements and call to action buttons, maintaining brand consistency with the reference examples.
- Body and headline font: 'Inter', a grotesque sans-serif for a clean and neutral appearance, in line with modern app design trends.
- Use clear, minimalist icons to represent menu categories and order status, ensuring quick visual understanding.
- Adopt a card-based layout for menu items and order details, aligning with Google Flow/Firebase Studio's user interface design, which aids content organization and visual appeal.
- Incorporate subtle transitions and animations for order status updates and page navigation to enhance user engagement without being intrusive.
